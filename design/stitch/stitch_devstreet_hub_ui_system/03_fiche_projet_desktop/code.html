Contexte et impact local

Architecture Résiliente

Dans les marchés de quartier à Bamako, Dakar et Abidjan, les interruptions de courant et les pannes réseau coupent régulièrement les commerces de leurs outils comptables en ligne. Stock fonctionne sur une architecture locale décentralisée : chaque transaction est validée localement sur le terminal du commerçant, stockée en base chiffrée, puis synchronisée en différé dès qu'une connectivité 3G/4G est restaurée.
