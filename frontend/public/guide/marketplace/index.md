# Marketplace — vue d’ensemble

La marketplace transforme votre présence DevStreet (profil, disponibilités, réputation) en **opportunités** : missions freelance, CDD, CDI, stages.

## Ce que vous pouvez faire

| Si vous êtes développeur | Si vous recrutez |
| --- | --- |
| Parcourir les offres ouvertes | Publier et gérer des offres |
| Voir un **score** sur chaque offre | Recevoir des candidatures **triées par score** |
| Postuler avec un message | Retenir / refuser / accepter |
| Suivre vos candidatures | Swiper des talents et remplir un **vivier** |
| Gérer votre calendrier | Consulter l’annuaire |
| Générer un **CV PDF** à jour | Télécharger le CV si autorisé |
| Élargir votre réseau | Faire du réseau aussi (double profil) |

## Le menu

| Section | Entrées | Qui la voit |
| --- | --- | --- |
| **Général** | Explorer les offres ; Administration (si droits) | Tout le monde (admin selon droits) |
| **Espace dev** | Réseau, Mes candidatures, Disponibilités, Mon CV | Profil développeur (ou invitation à le créer) |
| **Entreprise** | Mes offres, Talents, Vivier | Entreprise (ou invitation à la créer) |

Vous pouvez cumuler **dev + entreprise** : les deux blocs apparaissent. Sur le Réseau, « Agir en tant que » choisit le profil actif pour les swipes.

## Le score (sur 100)

Il classe les offres (côté dév) et les candidatures / talents (côté recruteur) :

| Critère | Poids | Idée |
| --- | --- | --- |
| Compétences | 40 | Correspondance skills offre ↔ profil |
| Expérience | 15 | Années vs niveau attendu |
| Localisation | 15 | Ville, pays, remote |
| Budget | 10 | Tarif vs fourchette |
| Disponibilité | 10 | Calendrier vs dates de mission |
| Réputation | 10 | Avis et parcours |

Une part « IA » peut être annoncée comme bientôt disponible. Un recruteur peut déjà décrire un besoin en langage naturel pour obtenir un **brouillon d’offre**.

## Règles utiles

- Vous ne postulez **pas** à une offre de votre propre entreprise.
- Une candidature **acceptée** est définitive : e-mail + période Occupé sur le calendrier du développeur.
- L’e-mail d’un profil n’est visible que pour soi, une connexion réseau, un candidat sur votre offre, ou un membre du vivier.
- L’administration marketplace est réservée aux opérateurs — le quotidien se passe dans ce menu.
