# Mes candidatures

**Où le trouver :** Marketplace → Espace dev → Mes candidatures

## À quoi ça sert

Suivre **toutes** les candidatures que vous avez envoyées : de l’envoi jusqu’à la décision de l’entreprise. Si on vous accepte, votre calendrier de disponibilités se met à jour tout seul.

## Le bandeau en haut

| Indicateur | Signification |
| --- | --- |
| Envoyées | En attente de réponse |
| Présélectionnées / Retenues | Vous êtes en shortlist |
| Acceptées | Missions validées (éventuellement à venir) |
| Refusées | Clôturées sans suite |

## Chaque candidature

Sur la carte :

1. **Titre de l’offre** (cliquable) et nom de l’entreprise.
2. Chronologie :
   - **Envoyée** + date ;
   - puis, si décidé : **Retenue**, **Refusée** ou **Acceptée** + date.
3. Si **Acceptée** : un message vous explique qu’une période Occupé a été ajoutée, avec un lien vers [Mes disponibilités](disponibilites.md).

## Comment ça avance

```
Envoyée → (parfois Retenue) → Acceptée ou Refusée
```

- Une acceptation est **définitive**.
- Vous recevez en général un e-mail.
- La période de mission sur le calendrier n’est pas modifiable à la main.

## Aucune candidature ?

Un bouton vous renvoie vers [Explorer les offres](explorer-offres.md).

## Questions fréquentes

| Situation | Explication |
| --- | --- |
| Pas de long motif de refus | L’écran suit surtout le **statut**, pas forcément un commentaire détaillé |
| Mission absente du calendrier | Vérifiez que le statut est bien Acceptée, puis rechargez Disponibilités |
| Impossible de postuler une 2ᵉ fois | Une seule candidature par offre |
