# Réseau

**Où le trouver :** Marketplace → Espace dev → Réseau

## À quoi ça sert

Découvrir d’autres membres (développeurs et entreprises) par **cartes à glisser**, puis créer une **connexion** quand le like est réciproque. Utile pour élargir votre réseau hors d’une offre précise.

## Agir en tant que…

Si vous avez à la fois un profil **dev** et **entreprise**, choisissez en haut du deck si vous swappez en tant que développeur ou en tant qu’entreprise. Vos likes et vos demandes suivent ce choix.

## Le deck (swipe)

| Action | Effet |
| --- | --- |
| Droite / Valider | Vous proposez une connexion |
| Gauche / Passer | Vous passez |
| Annuler | Annule le dernier choix |
| Voir le profil | Ouvre la fiche |

Sur la carte : type (Dev / Entreprise), nom, accroche, compétences, indices (compétences en commun, ville, entreprise vérifiée, années d’expérience…).

Quand le paquet est fini, un message vous invite à revenir plus tard. Si l’autre personne a aussi liké, un écran **Vous êtes connectés** s’affiche.

## Mon réseau

Lien sous le sélecteur (avec pastille s’il y a des demandes reçues) :

| Onglet | Contenu |
| --- | --- |
| Connexions | Membres matchés, date, e-mail si visible |
| Demandes en attente | Likes que **vous** avez envoyés, pas encore répondus |
| Demandes reçues | **Accepter** ou **Refuser** |

Accepter = connexion créée. La personne disparaît du deck au prochain rafraîchissement.

## Après une connexion

Vous pouvez souvent contacter la personne (e-mail) selon les règles de visibilité. Une connexion peut aussi débloquer certaines infos de profil / CV.

Annuler un like qui avait déjà créé une connexion peut **supprimer** cette connexion.

| --- | --- |

| Like réciproque | Like unilatéral |
