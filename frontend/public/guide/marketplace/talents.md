# Talents

**Où le trouver :** Marketplace → Entreprise → Talents  
*(Réservé aux recruteurs / entreprises.)*

## À quoi ça sert

Trouver des développeurs **sans attendre** qu’ils postulent à une offre. Deux façons :

1. **Annuaire** — liste filtrable, recherche, fiches.
2. **Mode swipe** — cartes à glisser : à droite vous **gardez** le profil dans votre [vivier](vivier.md).

Ce n’est pas le [Réseau](reseau.md) : ici, garder un profil ne crée pas une connexion réciproque. Ça l’ajoute au vivier de **votre entreprise**.

## Annuaire

En haut : titre **Annuaire des talents**, boutons **Mode swipe** et **Vivier**.

Vous pouvez :

- chercher par nom, accroche ou techno ;
- filtrer par compétence, remote, disponibilité, pays.

Chaque carte montre le nom, le remote, la dispo, le lieu, l’expérience, quelques compétences et la note. Un clic ouvre le profil.

Si rien ne correspond : « Aucun profil ne correspond à ces filtres. »

## Mode swipe (Découvrir)

Ouvrez **Mode swipe**. Pour chaque carte :

| Action | Résultat |
| --- | --- |
| Droite / Valider | Le profil est **gardé dans le vivier** |
| Gauche / Passer | Vous passez |
| Annuler | Annule le dernier choix |
| Voir le profil | Ouvre la fiche sans forcément garder |

Sur la carte, vous voyez aussi la disponibilité et un **score de recommandation** (surtout utile si vous avez des offres ouvertes). Un compteur **Vivier : n** suit votre session.

## Différence avec le Réseau

| Talents | Réseau |
| --- | --- |
| Vous recrutez | Vous élargissez votre réseau |
| Garder → vivier entreprise | Like → connexion si l’autre like aussi |
| Visible de tous les recruteurs de la boîte | Relation entre deux membres |

## Conseils

- Filtrez l’annuaire avant de swiper pour cibler stack et pays.
- Traitez ensuite les profils gardés dans le [vivier](vivier.md) (voir le profil, contacter si l’e-mail est visible).
- Publier des offres aide le moteur à proposer de meilleurs scores sur les cartes.
