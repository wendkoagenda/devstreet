# Mon CV automatique

**Où le trouver :** Marketplace → Espace dev → Mon CV  
*(Il faut un profil développeur.)*

## Ce que DevStreet apporte (et ce que ce n’est pas)

Sur beaucoup de plateformes, le CV est un fichier Word/PDF que vous uploadez et qui **vieillit** dès le lendemain. Sur DevStreet, le CV est **généré automatiquement** à partir de votre profil marketplace :

- vous mettez à jour compétences, expériences, prestations, bio, liens ;
- l’aperçu A4 et le PDF se reconstruisent **à la demande** (pas de fichier mort à maintenir) ;
- vous choisissez le **style** (couleurs, police, mise en page) et **qui** peut télécharger le PDF ;
- le même contenu alimente aussi le **score** des offres, l’annuaire talents, le réseau et la fiche publique.

Ce n’est **pas** un éditeur de texte libre type Canva : le contenu vient du profil. Pour enrichir le CV, vous enrichissez le profil (voir [Mon profil](../compte/mon-profil.md)).

## Parcours type (5 minutes)

1. Ouvrez **Mon CV** : bandeau de complétude + aperçu A4.
2. Si des éléments manquent (accroche, compétences, expérience…), cliquez **Compléter** → section profil dev.
3. Cliquez l’icône **engrenage** → panneau **Personnaliser mon CV**.
4. Changez couleur / police / bande : l’aperçu suit **en direct**.
5. Badge **Aperçu non enregistré** → **Enregistrer le style** (ou Annuler).
6. Réglez **Qui peut télécharger mon CV** (enregistré tout de suite).
7. **Télécharger (PDF)** : le fichier suit exactement ce que vous voyez (même un style pas encore sauvé).

## Écran : de haut en bas

### 1. Bandeau de stats (complétude)

Deux indicateurs principaux :

| Indicateur | Signification |
| --- | --- |
| **Complétude du profil** | Pourcentage sur 8 critères utiles au matching et au CV |
| **À compléter** | Nombre d’éléments manquants + aperçu des 2 premiers + lien Compléter |

Les 8 critères :

| Clé | Ce qu’il faut renseigner |
| --- | --- |
| Accroche | Headline courte sous votre nom |
| Présentation | Bio |
| Ville | Localisation |
| Langues | Au moins une langue |
| Compétences | **Au moins 3** compétences avec niveau |
| Expérience | Au moins **une** expérience pro |
| Lien | GitHub, LinkedIn **ou** portfolio |
| Tarif journalier | Votre TJM / tarif renseigné |

Un profil à 100 % n’affiche plus la liste « à compléter », mais **Profil complet**.

### 2. En-tête de page

- Titre **Mon CV automatique**.
- Bouton **Paramètres** (engrenage) : ouvre le panneau de style.
- Badge violet **Aperçu non enregistré** dès qu’un réglage de style diffère de la version sauvée.
- Phrase d’aide : le CV est construit depuis profil / compétences / expériences ; mention **Visible par : …** selon la visibilité actuelle.
- Boutons :
  - **Annuler** / **Enregistrer le style** (seulement si aperçu modifié) ;
  - **Télécharger (PDF)** (toujours).

### 3. Aperçu A4

Feuille type CV, mise à l’échelle de l’écran (jamais agrandie au-delà du format réel) :

**Bande latérale** (gauche ou droite) :

- photo (ronde / carrée) ou initiales si pas de photo / photo masquée ;
- **Contact** : e-mail, téléphone (si renseigné sur le profil), ville/pays, liens raccourcis ;
- **Compétences** : jusqu’à 14, en barres, points ou texte + niveau (Notions → Expert) ;
- **Langues** ;
- **Expérience** (années) ;
- **Réputation** : note moyenne /5 et nombre d’avis publics.

**Colonne principale** :

- nom + accroche ;
- **Profil** (bio) ;
- **Expériences** : poste, entreprise, dates (dont « aujourd’hui » si en cours), lieu, description, technologies ;
- les **prestations** packagées actives apparaissent surtout dans le **PDF** (section dédiée) ; vous pouvez les afficher/masquer dans les réglages de sections.

Si vous n’avez **aucune expérience**, un message sous l’aperçu propose d’en ajouter depuis le profil.

## Personnalisation détaillée

Panneau latéral **Personnaliser mon CV** (aperçu live).

### Couleur principale

Presets : Violet, Bleu, Vert, Orange, Rose, Rouge, Ardoise — plus une **couleur libre** (pipette). La couleur colore la bande, les titres, les barres de compétences, etc.

### Police

| Option | Effet |
| --- | --- |
| Moderne | Sans-serif, lisible écran |
| Classique | Serif, plus « papier » |
| Technique | Mono, ton développeur |

### Mise en page

Combinaisons bande × côté :

- bande **pleine** ou **claire** ;
- à **gauche** ou à **droite**.

Quatre vignettes dans le panneau illustrent le résultat.

### Photo

| Option | Effet |
| --- | --- |
| Ronde | Avatar circulaire (photo du compte si présente) |
| Carrée | Avatar avec coins légèrement arrondis |
| Sans | Pas de bloc photo ; plus d’espace pour le contenu |

### Compétences (rendu)

| Style | Affichage |
| --- | --- |
| Barres | Jauge 0–5 |
| Points | Cinq pastilles |
| Texte | Libellé de niveau (Notions, Débutant, Intermédiaire, Avancé, Expert) |

### Densité

Compacte / Standard / Aérée : resserre ou aère interlignes et marges (aperçu et PDF).

### Sections affichées

Cases à cocher :

- Contact, Compétences, Langues, Réputation, Profil (bio), Expériences, Prestations.

Décocher masque la section dans l’aperçu (et le PDF pour les sections concernées).  
Astuce affichée à l’écran : *« Les prestations n’apparaissent que dans le PDF »* — même si l’aperçu ne les montre pas toutes, le réglage contrôle quand même leur présence à l’export.

### Qui peut télécharger mon CV

Sélecteur **enregistré immédiatement** (pas besoin d’« Enregistrer le style ») :

| Choix | Qui peut obtenir le PDF |
| --- | --- |
| **Les entreprises** | Membres rattachés à une entreprise (recruteurs) |
| **Tout le monde** | Les membres autorisés à voir votre profil peuvent télécharger |
| **Moi uniquement** | Vous seul |

Sur la fiche publique d’un autre membre, le bouton **Télécharger le CV** n’apparaît que si vous y êtes autorisé.

### Pied du panneau

| Action | Effet |
| --- | --- |
| Style d’origine | Remet les couleurs / police / bande par défaut |
| Annuler | Annule l’aperçu non enregistré |
| Enregistrer | Garde le style pour les prochains PDF |

| **Explorer les offres** | Le même profil alimente le score |

## Téléchargement PDF

- Le PDF est reconstruit à chaque téléchargement : toujours à jour avec le profil.
- Si vous avez changé le style sans encore enregistrer, le PDF peut quand même coller à l’aperçu à l’écran.

## Bonnes pratiques

1. Visez au moins **3 compétences** et **1 expérience** avant de partager votre profil.
2. Ajoutez GitHub / LinkedIn / portfolio : ils apparaissent en contact et comptent pour la complétude.
3. Activez **ouvert aux opportunités** sur le profil pour être trouvé (réseau, talents) — c’est distinct de qui peut télécharger le PDF.
4. Pour candidater sérieusement : visibilité au minimum **Les entreprises**, sinon les recruteurs ne téléchargent pas.
5. Les **prestations** (ex. « landing page en 5 jours ») mettent en avant vos forfaits : renseignez-les si vous en proposez.

## Erreurs fréquentes

| Situation | Cause probable | Que faire |
| --- | --- | --- |
| Aperçu vide / squelette | Profil ou réglages encore en chargement | Attendre ; vérifier profil dev créé |
| « Impossible de télécharger » | Réseau / session / droit | Se reconnecter ; vérifier visibilité |
| Pas de bouton CV sur mon profil public vu par un ami | Visibilité « Moi uniquement » ou lecteur non autorisé | Assouplir la visibilité |
| PDF sans expériences | Aucune expérience en base | Les ajouter dans Mon profil |
| Style perdu après rechargement | Aperçu non enregistré | Cliquer Enregistrer le style |

## Résumé

**Mon CV** = vitrine PDF **vivante** de votre profil DevStreet : style pro personnalisable, contrôle de diffusion, contenu unique partagé avec le matching marketplace. Enrichissez le profil une fois ; le CV, les offres et les recruteurs en profitent ensemble.
