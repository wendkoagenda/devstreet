# Explorer les offres

**Où le trouver :** Marketplace → Général → Explorer les offres

## À quoi ça sert

Parcourir les **offres ouvertes**, comprendre pourquoi une offre vous correspond (score), postuler, puis suivre le dossier dans [Mes candidatures](candidatures.md).

Vous ne pouvez **pas** postuler à une offre de **votre** entreprise : le bouton devient **Gérer l’offre**.

## La liste

1. Recherchez (missions, technos, entreprises).
2. Affinez avec les filtres (type, remote, pays…).
3. Les offres les mieux adaptées à votre profil remontent souvent en tête grâce au **score**.
4. Un bandeau peut afficher : offres ouvertes, bien adaptées, candidatures déjà envoyées.

## Fiche d’une offre

| Bloc | Ce que vous y trouvez |
| --- | --- |
| En-tête | Titre, entreprise (éventuellement vérifiée), type, mode, dates |
| Description | Mission / poste, compétences attendues (souvent marquées si vous les avez) |
| Budget / démarrage | Fourchettes et date de démarrage |
| Pourquoi cette offre ? | Score total + détail (compétences, expérience, lieu, budget, dispo, réputation) |
| Actions | Postuler, Suivre ma candidature, Gérer, ou Offre fermée |

### Comment lire le score

Le score sur 100 combine notamment :

- Compétences (le plus important)
- Expérience
- Localisation
- Budget
- Disponibilité
- Réputation

Une part « IA » peut être annoncée comme bientôt disponible dans l’interface.

## Postuler

1. L’offre est **ouverte**, vous n’avez pas déjà candidaté, ce n’est pas la vôtre.
2. Cliquez **Postuler**, rédigez un message et confirmez avec votre profil.
3. Après succès, vous êtes renvoyé vers le suivi — bouton **Suivre ma candidature**.
4. Statut de départ : **Envoyée**.

## Selon la situation

| Situation | Ce que vous voyez |
| --- | --- |
| Ouverte, pas encore candidaté | **Postuler** |
| Déjà candidaté | Badge de statut + **Suivre ma candidature** |
| Fermée | Badge Offre fermée |
| Votre offre | **Gérer l’offre** |

## Conseils candidat

- Complétez votre profil et [Mon CV](cv.md) avant de postuler.
- Lisez « Pourquoi cette offre ? » pour savoir quoi améliorer (skills, dispos…).
- Dans le message : stack, disponibilité, prétentions — concret et court.
