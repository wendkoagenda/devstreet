# Mes offres

**Où le trouver :** Marketplace → Entreprise → Mes offres  
*(Réservé aux recruteurs / entreprises.)*

## À quoi ça sert

Votre espace pour **publier** des missions ou postes, suivre les candidatures, les trier par score, et vous appuyer sur des profils recommandés.

Vous ne voyez ici que les offres de **votre entreprise** — pas toute la plateforme.

## Liste des offres

Chaque ligne affiche :

- titre + statut (**brouillon**, **ouverte**, **clôturée**) ;
- type de contrat, remote / hybride, etc. ;
- date de publication si l’offre est ouverte ;
- nombre de candidatures + pastille des **nouvelles** non encore examinées.

En haut : **Publier une offre** (formulaire, parfois avec une aide pour générer un brouillon à partir d’un besoin décrit en langage naturel). Un clic sur une offre ouvre la page de gestion.

### Bandeau

| Indicateur | Signification |
| --- | --- |
| Offres ouvertes | Visibles des candidats |
| Brouillons / clôturées | Non publiées ou terminées |
| Candidatures à traiter | Nouvelles, pas encore décidées |
| Vues des offres | Attractivité cumulée |

## Gérer une offre

### En-tête

- Titre + statut, faits + **nombre de vues**.
- **Modifier**, **Publier** (passer en ouverte) ou **Clôturer** (plus de nouvelles candidatures).

### Candidatures reçues

Tableau trié par **score** :

| Colonne | Contenu |
| --- | --- |
| Candidat | Photo, nom (lien profil), accroche, date, message |
| Score | Pertinence par rapport à l’offre |
| Statut | Envoyée → Retenue → Refusée / Acceptée |
| Décision | Contacter, Retenir, Refuser, Accepter |

**Décisions :**

- **Retenir** — shortlist, sans engagement final.
- **Refuser** — fin du parcours pour ce candidat.
- **Accepter** — définitif : e-mail au candidat + période Occupé ajoutée à son calendrier ; plus de changement de statut ensuite.

Ouvrir le profil permet de voir compétences, expériences, et éventuellement **télécharger le CV** si la personne l’autorise (voir [Mon CV](cv.md)).

### Profils recommandés

Sous le tableau : talents classés pour **cette** offre (score, skills, ville, badge « A déjà postulé »). Utile pour solliciter quelqu’un qui n’a pas encore candidaté.

## Cycle recommandé

1. Brouillon → compétences, budget, dates, remote.
2. Publier → suivre vues et candidatures.
3. Shortlist → échanges (messagerie / e-mail).
4. Accepter → calendrier du développeur mis à jour.
5. Clôturer quand le besoin est pourvu.

## Questions fréquentes

| Problème | Explication |
| --- | --- |
| Impossible de publier | Droits entreprise, offre incomplète, ou message d’erreur à l’écran |
| Pas de bouton Contacter | Coordonnées encore masquées (candidature / vivier / connexion) |
| Acceptée encore « décidable » | Normalement non — si les boutons sont bloqués, c’est voulu |
| Scores tous bas | Compétences de l’offre trop étroites par rapport aux profils dispo |
