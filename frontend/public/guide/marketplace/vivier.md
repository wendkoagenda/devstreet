# Vivier de talents

**Où le trouver :** Marketplace → Entreprise → Vivier  
*(Réservé aux recruteurs / entreprises.)*

## À quoi ça sert

C’est la liste des profils **gardés** par les recruteurs de votre entreprise — surtout en glissant à droite en [mode swipe](talents.md). Toute l’équipe recruteur voit le **même** vivier.

Idéal pour constituer un pool avant (ou sans) publier une offre à chaque profil intéressant.

## Comment le remplir

1. Allez dans **Talents → Mode swipe**.
2. Glissez à **droite** (ou Validez) : tampon **Vivier**.
3. Le profil apparaît ici avec « Gardé par … le … ».

Si le vivier est vide, l’écran vous invite à garder des profils et propose un lien vers l’annuaire.

## Ce que vous voyez

En haut :

| Indicateur | Signification |
| --- | --- |
| Talents gardés | Total dans le vivier |
| Ajoutés cette semaine | Nouveautés |
| Ouverts aux opportunités | Profils « open to work » |

Sur chaque carte : photo, nom, accroche, ville, compétences, qui l’a gardé et quand.

Actions :

- **Voir le profil**
- **Contacter** (e-mail) — seulement si les coordonnées sont visibles pour vous

## Quand peut-on contacter ?

En général, l’e-mail d’un talent devient visible après une candidature sur votre offre, une connexion réseau, ou l’ajout au vivier — selon les règles de confidentialité. Si le bouton Contacter n’apparaît pas, ouvrez le profil ou utilisez la messagerie selon ce qui est proposé.
