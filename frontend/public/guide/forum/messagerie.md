# Messagerie

**Où le trouver :** menu Principal → Messagerie

## À quoi ça sert

Échanger en **privé** avec un autre membre — pour prolonger une discussion, parler recrutement ou s’entraider sans tout exposer sur le fil public.

## Ouvrir une conversation

| Depuis | Comment |
| --- | --- |
| Messagerie | Cherchez un membre ou reprenez un fil existant |
| Profil d’un membre | Bouton pour écrire / ouvrir la conversation |
| Membres d’une communauté | Action message si elle est proposée |

S’il existe déjà une conversation entre vous deux, c’est **la même** qui se rouvre — peu importe qui a écrit en premier.

## Messages et historique

Vous écrivez du texte ; l’historique reste après un rechargement. Les nouveaux messages peuvent arriver en direct pendant que vous êtes sur la page.

## Non lus

- Une pastille sur le menu indique des conversations non lues.
- Dans la liste, une conversation non lue est aussi signalée.
- Ouvrir le fil la marque en général comme lue.

## Confidentialité

- Seuls **les deux** participants voient et écrivent dans la conversation.
- Un retour anonyme sur une candidature ne donne **pas** accès à un message privé vers l’auteur anonyme.

## Compte entreprise seule

Même sans forum ni projets dans le menu, la messagerie reste disponible — pratique pour échanger avec des candidats ou partenaires.
