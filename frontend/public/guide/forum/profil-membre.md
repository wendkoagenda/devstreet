# Profil membre

**Où le trouver :** en cliquant sur le nom ou la photo d’un membre (fil, messagerie, réseau, talents…)

## À quoi ça sert

La vitrine publique d’un membre : qui il est, son activité, son profil développeur et/ou entreprise, et les actions Suivre, Message ou télécharger le CV si c’est autorisé.

## Ce que vous pouvez voir

| Zone | Contenu typique |
| --- | --- |
| En-tête | Nom, pseudo, photo, « open to work » |
| Communauté | Publications / activité visible |
| Onglet Dev | Accroche, compétences, expériences, liens |
| Onglet Entreprise | Fiche société si elle existe |
| Actions | Suivre, message, télécharger le CV (selon les droits) |

Sur **votre** propre profil, vous voyez plutôt **Mettre à jour mon profil** que Contacter. Détail : [Mon profil](../compte/mon-profil.md).

## Suivre un membre

- Libre, sans demande d’accord.
- Vous ne pouvez pas vous suivre vous-même.
- Suivre deux fois ne crée qu’une seule relation.
- Effet : les publications **auxquelles vous avez déjà accès** de cette personne remontent mieux (fil Abonnements / résumé).
- Limite : suivre quelqu’un **ne débloque pas** un espace privé.

## Coordonnées et CV

L’e-mail, Contacter ou le PDF du CV ne sont pas toujours visibles. En général, c’est possible si :

- c’est **vous** ;
- vous êtes **connectés** via le réseau ;
- la personne a candidaté sur une offre de votre entreprise ;
- elle est dans votre **vivier** ;
- et les réglages de visibilité du CV l’autorisent.

Plus de détail : [Mon CV](../marketplace/cv.md) et [Réseau](../marketplace/reseau.md).
