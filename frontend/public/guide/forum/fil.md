# Fil général

**Où le trouver :** menu Principal → Forum

## À quoi ça sert

Lire ce qui se passe dans la communauté, publier, filtrer par tags, et ouvrir une publication pour commenter ou utiliser les actions du type (voter, accepter une réponse, etc.).

## L’écran

1. **Zone pour publier** — type, titre, texte, images, et champs selon le type (lien d’app, options de sondage…).
2. **Liste** — cartes récentes : auteur, type, extrait, likes, commentaires.
3. **Filtre par tag** — via les tags suivis dans la barre latérale (voir [Favoris](favoris.md)).

## Publier en 5 étapes

1. Ouvrez le formulaire sur le fil (ou dans une communauté / chaîne).
2. Choisissez le **type** — détail dans [Types de publication](types-publication.md).
3. Titre + texte ; ajoutez des images si besoin.
4. Remplissez les champs du type (lien d’essai, options…).
5. Validez : la publication apparaît dans le fil ; un clic ouvre le détail.

Une publication peut :

- rester sur le **fil général** ;
- ou être liée à **une** communauté / chaîne (visible selon qui a accès à cet espace).

## Sur une publication

| Action | Comportement |
| --- | --- |
| Like | Un like par personne ; vous pouvez le retirer |
| Commenter | Ajoute un commentaire |
| Répondre | Répond à un commentaire de **cette** publication |
| Like d’un commentaire | Idem, un par personne |
| Profil de l’auteur | Ouvre sa fiche |
| Actions du type | Essayer l’app, accepter une réponse, voter, décider… |

## Page de détail

Vous y trouvez le contenu complet, les médias, les commentaires / retours, et les boutons propres au type (fermer un sondage, retenir une option, « Ça m’a aidé aussi »…).

## Ce qui peut être refusé

- Commenter en rattachant à une autre publication.
- Liker deux fois (ça ne compte qu’une fois).
- Lire un espace privé sans y être membre (ni lien d’invitation valide).
- Publier dans un espace où vous n’avez pas le droit.

## Filtrer par tag

Les tags favoris permettent de ne garder que certains sujets. Un tag **ne révèle pas** un espace auquel vous n’avez pas accès.
