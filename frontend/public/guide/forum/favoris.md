# Favoris et tags

**Où le trouver :** menu Principal → Favoris  
Raccourci : barre latérale → tags suivis

## À quoi ça sert

Suivre des **sujets** (tags) pour retrouver plus facilement les publications qui vous intéressent, et filtrer le fil général — sans créer un second forum.

## Page Favoris

1. Ouvrez **Favoris**.
2. Suivez (ou ne plus suivre) les tags proposés / recherchés.
3. Vos tags suivis apparaissent aussi dans le sélecteur de la barre latérale.

## Filtrer le fil

| Action | Effet |
| --- | --- |
| Choisir un tag dans la barre latérale | Le fil ne montre plus que ce sujet |
| Désélectionner | Retour au fil complet |

Important : un tag ne révèle **pas** les publications d’un espace auquel vous n’avez pas accès. Vos droits de lecture restent les mêmes.
