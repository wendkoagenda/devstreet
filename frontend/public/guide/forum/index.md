# Forum — vue d’ensemble

Le forum, c’est l’espace pour **échanger** avec les autres membres : poser une question, faire tester une app, voter, s’entraider. Cinq types de publications, chacun avec ses boutons et ses règles.

## Dans le menu Principal

| Entrée | À quoi ça sert |
| --- | --- |
| Forum | Lire le fil et publier |
| Communautés | Groupes thématiques (rejoindre, publier entre membres) |
| Chaînes | Infos diffusées par les admins de la chaîne |
| Messagerie | Messages privés à deux |
| Favoris | Tags que vous suivez + filtre du fil |

Une pastille sur Communautés, Chaînes ou Messagerie signifie qu’il y a de l’activité non lue.

## Qui voit ce menu ?

La plupart des comptes avec un accès communauté (souvent après avoir créé un profil développeur).

Avec un compte **entreprise seule**, vous n’avez pas Forum / Communautés / Chaînes / Favoris / Projets — mais la **Messagerie** reste.

## À retenir simplement

- Une publication a **un** type (Discussion, Entraide, Application, Aide au choix, Sondage).
- Elle peut rester sur le fil général **ou** être liée à **une** communauté / chaîne.
- Suivre un membre n’ouvre pas un espace privé.
- La messagerie est indépendante des publications.

## Que faire selon votre besoin ?

| Objectif | Chemin |
| --- | --- |
| Question ouverte | Fil → Discussion |
| Débloquer un bug | Fil → Entraide technique → accepter une réponse |
| Faire tester une app | Fil → Application → collecter les retours |
| Trancher entre options | Fil → Aide au choix |
| Opinion mesurable | Fil → Sondage |
| Groupe local / thématique | Communautés |
| Infos push (newsletter interne) | Chaînes |
| Continuer en privé | Messagerie ou profil du membre |
