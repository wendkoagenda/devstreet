# Chaînes

**Où le trouver :** menu Principal → Chaînes

## Différence avec une communauté

| | Communauté | Chaîne |
| --- | --- | --- |
| Modèle | Discussion entre pairs | Canal de diffusion |
| Qui publie | Tous ou admins (réglable) | **Admins uniquement** |
| Participation | Adhésion | Abonnement |
| Commentaires | Selon les droits | **Ouverts ou fermés** (réglage) |
| Likes | Oui | Oui, même si les commentaires sont fermés |

Une chaîne n’est pas « une communauté en lecture seule » : c’est un canal d’annonces / infos.

## Créer / s’abonner

1. Créez la chaîne (nom, description, public ou par lien) → vous êtes super admin.
2. Les autres **s’abonnent** (ou se désabonnent).
3. Se désabonner retire l’accès lié à l’abonnement.

## Accès par lien

Même logique que les [communautés](communautes.md) : prévisualisation optionnelle, révocation, pas d’interaction avant abonnement si exigé.

## Commentaires ouverts ou fermés

| État | Effet |
| --- | --- |
| Fermés | Plus de nouveaux commentaires ; les likes restent ; les anciens commentaires restent visibles |
| Rouverts | Les commentaires reprennent |

## Abonnements et résumé

Les nouveautés des chaînes suivies alimentent :

- le fil **Abonnements** ;
- le **résumé quotidien** dans l’application (pas forcément un e-mail).
