# Communautés

**Où le trouver :** menu Principal → Communautés

## À quoi ça sert

Des **groupes thématiques** avec membres et rôles : club tech, cohorte, communauté locale… L’historique reste lié à DevStreet (contrairement à un chat externe).

Ce n’est **pas** une chaîne : ici on discute entre pairs (selon le réglage « qui peut publier »).

## Créer une communauté

1. Communautés → créer.
2. Nom + description.
3. Choisissez l’accès :
   - **Public** — visible / rejoignable selon l’écran ;
   - **Par lien** — on entre avec une invitation.
4. Vous devenez **super administrateur** : vous ne pouvez pas être exclu ni rétrogradé tant que l’espace existe.

## Rejoindre

| Accès | Comment |
| --- | --- |
| Public | Bouton **Rejoindre** sur la fiche |
| Par lien | Ouvrir le lien d’invitation reçu |

Rejoindre deux fois ne crée pas de doublon.

### Liens d’invitation

Un admin crée un lien et choisit, **pour ce lien** :

| Option | Effet |
| --- | --- |
| Prévisualisation **oui** | La personne lit les publications, mais ne publie / commente / like **pas** avant d’avoir rejoint |
| Prévisualisation **non** | Elle doit rejoindre d’abord |

Sans adhésion ni lien valide : l’espace et ses posts restent **invisibles**. Un lien **révoqué** ne fonctionne plus.

## Qui publie ?

Selon le réglage de la communauté : tout le monde, ou seulement les admins. Les non-membres ne publient pas (sauf prévisualisation lecture seule via lien, sans interaction).

## Rôles utiles

| Rôle | Idée |
| --- | --- |
| Super admin | Créateur ; droits complets, permanent |
| Admin | Modère, gère invitations et réglages |
| Membre | Lit, et publie si le réglage l’autorise |
