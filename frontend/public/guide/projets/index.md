# Projets — vue d’ensemble

**Où le trouver :** menu Projets

Les comptes **entreprise seule** ne voient pas cette section (ils restent sur la marketplace).

## Deux entrées

| Entrée | À quoi ça sert |
| --- | --- |
| Explorer les projets | Découvrir les projets de la plateforme |
| Mes projets | Voir ceux dont **vous** êtes propriétaire |

## Ce que vous pouvez faire

- Créer un projet (de l’idée à la publication).
- Proposer des tâches et des contributions.
- Examiner les propositions (accepter ou refuser — sans lancer un merge Git tout seul).
- Utiliser l’**atelier IA** (si vous êtes propriétaire) pour transformer des idées en tâches.
- Demander de l’aide sur une tâche : ça peut publier un sujet sur le forum.

Ce n’est **pas** la marketplace (offres / candidatures), ni le fil général du forum — mais un projet peut être relié à une discussion forum.
