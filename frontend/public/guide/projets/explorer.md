# Explorer et créer un projet

**Où le trouver :** Projets → Explorer les projets · bouton **Créer un projet**

## Explorer

La page **Explorer les projets** montre les projets visibles, avec :

- recherche et filtre par technologie ;
- indicateurs (projets visibles, technologies) ;
- badges de statut : **Public**, **Brouillon**, **Archivé** ;
- un bouton **Créer un projet** si vous en avez le droit (sinon connexion / bouton masqué).

## Créer un projet

1. Cliquez **Créer un projet** (ou **Reprendre la création** si un brouillon existe).
2. Suivez les étapes : brouillon → accès Git → dépôt → initialisation.
3. Renseignez nom, description, licence (MIT souvent proposée), éventuellement une démo, et si le projet est public.
4. À la fin, vous arrivez sur la fiche du projet.

## Fiche d’un projet

Onglets : **Présentation** · **Code** · **Contribuer** · **Équipe**

Selon vos droits et si vous êtes propriétaire, vous pouvez notamment :

- mettre une étoile ;
- ouvrir la démo ;
- créer une tâche ;
- examiner les propositions ;
- préparer une contribution avec l’IA ;
- **publier** ou **archiver** (propriétaire).

## Tâches et contributions

1. Ouvrez une tâche depuis le projet.
2. Proposez une contribution si c’est autorisé.
3. Besoin d’aide ? **Demander de l’aide** peut préparer un message puis **Publier sur le forum**. Un lien « Voir sur le forum » apparaît ensuite.

## Examiner les propositions

Sur **Examiner les propositions** :

- vous **acceptez** ou **refusez** avec un motif ;
- vous ne pouvez pas vous auto-réviser ;
- **aucun merge Git n’est lancé automatiquement** — l’écran valide seulement la proposition dans DevStreet.

## Atelier IA

Réservé au propriétaire (avec consentement) :

- des suggestions d’idées / tâches ;
- action du type « En faire une tâche à relire » ;
- rien n’est publié tout seul.
