# Premiers pas (onboarding)

**Quand ça apparaît :** juste après l’inscription, ou quand le menu vous propose de créer un profil développeur / une entreprise.

## À quoi ça sert

Choisir ce que vous activez sur DevStreet :

- un profil **développeur** (chercher des missions, CV, réseau…) ;
- une **entreprise** (publier des offres, talents, vivier) ;
- **les deux**.

Vous pouvez passer l’étape et revenir plus tard via le menu (« Créer mon profil… ») ou [Mon profil](mon-profil.md).

## Les étapes

### 1. Quel profil souhaitez-vous ?

**Développeur** · **Entreprise** · **Les deux**.

### 2. Si vous choisissez Développeur

- Accroche, pays, ville.
- Compétences.
- Option « open to work » selon les écrans proposés.

### 3. Si vous choisissez Entreprise

- Nom de la société, secteur, taille, pays.
- Vous devenez en général propriétaire de cette entreprise.

### 4. Récapitulatif

| Votre choix | Vous arrivez sur |
| --- | --- |
| Entreprise seule | Mes offres |
| Développeur ou les deux | Le fil / l’accueil communauté |

## Ajouter un espace plus tard

Le menu peut afficher **Créer mon profil développeur** ou **Créer mon entreprise**. Vous reprenez alors seulement la partie manquante, sans tout recommencer.

## Compte entreprise seule

Si vous n’avez activé que l’entreprise :

| Vous avez | Vous n’avez pas (pour l’instant) |
| --- | --- |
| Marketplace (offres, talents, vivier…) | Forum principal |
| Messagerie | Projets |
| Votre profil et l’aide | Menu communauté complet |

Ajoutez un profil développeur pour débloquer le forum et les projets.

## Après l’onboarding — checklist

1. Compléter [Mon profil](mon-profil.md) (compétences, expériences, liens).
2. Régler [Mon CV](../marketplace/cv.md) (style + qui peut télécharger).
3. Indiquer vos absences dans [Mes disponibilités](../marketplace/disponibilites.md).
4. Côté entreprise : [publier une offre](../marketplace/mes-offres.md) ou explorer les [Talents](../marketplace/talents.md).
