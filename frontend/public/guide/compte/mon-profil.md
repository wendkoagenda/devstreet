# Mon profil

**Où le trouver :** votre avatar → profil, ou le lien de compte dans le menu

## À quoi ça sert

C’est votre carte d’identité sur DevStreet : ce que **vous** renseignez, et ce que **les autres** voient. Votre profil développeur alimente le CV, le score des offres, l’annuaire talents et le réseau.

## En pratique

1. Ouvrez votre profil.
2. Parcourez les onglets selon ce que vous avez activé : Publications, Mes projets, Contributions, **Profil dev**, **Entreprise**.
3. Cliquez **Modifier le profil** pour changer identité, « open to work », mot de passe ou sessions.
4. Enrichissez la section **dev** (compétences, expériences, liens, tarif) — ça met à jour [Mon CV](../marketplace/cv.md).
5. Si vous avez une société : complétez la section **Entreprise**.

## Les onglets

| Onglet | Ce que ça montre |
| --- | --- |
| Publications | Votre activité forum visible |
| Mes projets | Vos réalisations côté profil |
| Contributions | Vos contributions aux projets |
| Profil dev | Accroche, bio, compétences, expériences, liens, CV |
| Entreprise | Fiche de votre société |

Avec un compte **entreprise seule**, les onglets forum (publications, projets, contributions) n’apparaissent pas.

## Modifier le profil

Dans la boîte de dialogue :

| Zone | Vous pouvez |
| --- | --- |
| Identité | Prénom, nom, nom d’utilisateur |
| Disponibilité | Cocher **Open to work** (profil dév) — un anneau apparaît et vous êtes mieux mis en avant |
| Sécurité | Changer le mot de passe |
| Sessions | Voir les ordinateurs connectés |

La photo et la bannière se changent directement sur la page du profil.

## Profil développeur — quoi remplir

Accroche, présentation, ville, langues, **au moins 3 compétences** avec niveau, **une expérience**, un lien (GitHub, LinkedIn ou portfolio), et votre tarif journalier si vous êtes freelance.

La liste complète des critères de complétude est dans [Mon CV](../marketplace/cv.md).

## Open to work

Quand c’est activé :

- un anneau « ouvert aux opportunités » autour de votre photo ;
- vous apparaissez mieux dans le vivier, le réseau et les recommandations recruteurs.

## Ce que voient les autres

Ils ouvrent votre fiche publique : Suivre, Message, éventuellement télécharger le CV. Détail : [Profil membre](../forum/profil-membre.md).

Sur **votre** fiche, c’est l’édition qui s’affiche, pas Contacter.
