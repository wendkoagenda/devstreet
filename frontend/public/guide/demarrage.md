# Démarrage

## Qu’est-ce que DevStreet ?

Trois espaces dans **une** application :

1. **Forum** — publier, s’entraider (5 types de posts), communautés, chaînes, messagerie.
2. **Marketplace** — offres, candidatures, réseau, talents, CV PDF, disponibilités.
3. **Projets** — créer / rejoindre des projets, tâches, contributions.

Selon votre type de compte, le menu latéral montre tout ou une partie. Un compte **entreprise seule** n’a pas le forum ni les projets, mais garde marketplace et messagerie.

## Création de compte

À l’inscription, vous créez votre identité (e-mail, mot de passe, nom…). Ensuite vous activez ce dont vous avez besoin :

| Action | Effet |
| --- | --- |
| Créer mon **profil développeur** | Offres, candidatures, CV, réseau, disponibilités |
| Créer mon **entreprise** | Offres, talents, vivier |
| Les **deux** | Menu complet ; « Agir en tant que » sur le réseau |

Voir [Premiers pas](compte/onboarding.md) et [Mon profil](compte/mon-profil.md).

## Première heure utile

### Si vous cherchez une mission

1. Profil dév : accroche, au moins 3 compétences, 1 expérience, open to work.
2. Ouvrir **Mon CV** : vérifier l’aperçu, régler qui peut télécharger, tester un PDF.
3. **Explorer les offres** : lire « Pourquoi cette offre ? », postuler.
4. Suivre dans **Mes candidatures**.
5. Optionnel : **Réseau** pour des connexions hors offre.

### Si vous recrutez

1. Créer l’entreprise (vérification e-mail si proposée).
2. **Publier une offre** (brouillon possible via l’aide à la rédaction).
3. Suivre les **candidatures reçues** (score, retenir / refuser / accepter).
4. Remplir le **vivier** via Talents → mode swipe.
5. Télécharger le CV des candidats autorisés.

### Si vous venez pour la communauté

1. Publier une **discussion** ou une **entraide technique** sur le fil.
2. Rejoindre ou créer une **communauté**.
3. Utiliser la **messagerie** pour prolonger en privé.

## Confidentialité (rappel)

Les actions sensibles (accepter une candidature, accès à un espace privé, téléchargement d’un CV) sont toujours contrôlées. Si un bouton n’apparaît pas, c’est en général que vous n’y avez pas droit.
