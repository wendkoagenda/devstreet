# Administration marketplace

**Où le trouver :** Marketplace → Général → Administration  
*(Visible seulement si vous avez au moins une des pages autorisées.)*

## À quoi ça sert

Écrans de gestion des **données** marketplace : entreprises, compétences, profils, offres, candidatures, expériences, prestations, disponibilités, avis, likes, connexions, etc.

Chaque tuile n’apparaît que si vous y avez accès. Si la page est vide : « Vous n’avez accès à aucune page… ».

## Pour qui

L’équipe qui opère la plateforme — **pas** le parcours d’un recruteur ou d’un développeur au quotidien. Au quotidien, utilisez :

- [Mes offres](../marketplace/mes-offres.md)
- [Explorer les offres](../marketplace/explorer-offres.md)
- [Talents](../marketplace/talents.md) / [Vivier](../marketplace/vivier.md)
- [Mon CV](../marketplace/cv.md)

## Exemples de tuiles

| Tuile | Contenu |
| --- | --- |
| Entreprises | Sociétés présentes sur la marketplace |
| Compétences | Référentiel de skills |
| Profils | Profils marketplace |
| Offres / Candidatures | Offres et dossiers |
| Expériences / Prestations | Parcours et services |
| Disponibilités / Avis | Calendriers et notes |
| Swipes / Connexions | Likes et mises en relation |

## Prudence

Ici, vous voyez souvent **plus** que « mon entreprise seulement ». Une modification peut impacter plusieurs membres. Préférez les écrans utilisateur dès que c’est possible.
