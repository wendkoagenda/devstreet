# Administration — vue d’ensemble

Ces écrans sont réservés aux personnes qui gèrent la plateforme (ou qui ont reçu les droits nécessaires). Ce n’est **pas** le parcours quotidien d’un développeur ou d’un recruteur.

## Deux zones

| Zone | Où la trouver | Pour quoi |
| --- | --- | --- |
| **Plateforme** | Administration → Utilisateurs, Rôles | Comptes et droits d’accès |
| **Marketplace** | Marketplace → Général → Administration | Données de référence marketplace |

Pour publier une offre, postuler ou gérer votre CV, utilisez plutôt les pages utilisateur : [Mes offres](../marketplace/mes-offres.md), [Explorer les offres](../marketplace/explorer-offres.md), [Mon CV](../marketplace/cv.md), etc.
