# Suites des travaux de CD

Journaux de reproduction des évolutions CD, **une suite par période**.

Chaque fichier est nommé :

`SUITE_DES_TRAVAUX_DE_CD_<debut>_<fin>.md`

avec des dates `AAAA-MM-JJ`. Une suite cloturée n’est plus enrichie (sauf correction factuelle) ; la suivante démarre dans un nouveau fichier.
